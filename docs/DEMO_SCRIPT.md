# 系统演示脚本

## 演示前准备

1. 进入项目目录：`D:\CodexProjects\contract-review-system`
2. 启动服务：`.\run_server.ps1`
3. 打开页面：`http://127.0.0.1:8000/`
4. 准备一份包含风险的 Word、PDF 或图片合同。

## 5 分钟演示流程

### 第 1 分钟：说明痛点

合同审查通常存在四个问题：文件来源复杂、人工审查耗时、风险标准不统一、审查意见难以沉淀。本系统面向企业法务和采购审批场景，把合同导入、风险识别、修改建议和报告导出做成完整闭环。

### 第 2 分钟：上传合同

在首页点击“选择合同文件”，上传合同。系统支持 Word、PDF 和扫描件图片。上传后点击“开始智能审查”。

### 第 3 分钟：展示 Multi-Agent 协同

审查完成后重点展示“Agent 协同轨迹”：

- 协调者 Agent：接收合同并路由任务。
- 提取者 Agent：抽取主体、金额、期限和关键条款。
- 合规审查 Agent：识别风险并给出风险等级。
- 反馈与修改 Agent：生成修改建议和参考条款。
- 协调者 Agent：汇总报告。

### 第 4 分钟：展示审查结果

依次展示：

- 总体风险等级。
- 风险分和安全分。
- 风险维度评分。
- 风险点卡片。
- 修改建议卡片。
- 依据检索。

风险点默认压缩显示，点击卡片详情或“全部展开”可查看完整说明。

### 第 5 分钟：导出报告

点击下载 PDF、Word 或 JSON。说明系统不仅能聊天式回答，还能生成企业可交付的审查报告，并保留历史审查记录。

## 备用演示话术

如果现场网络或大模型 API 不稳定，可以把 `.env` 中 `ENABLE_LLM=false`，系统会自动退回规则审查模式，仍然能完成上传、解析、风险识别和报告导出。这一点体现了系统的可用性和容错能力。
