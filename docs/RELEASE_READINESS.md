## 已实现的安全边界

- 密码变更、角色变更、禁用和 refresh token 重放会撤销相关会话。
- refresh token 按 family 单次轮换，服务端仅保存随机标识和状态，不保存 bearer token。
- 登录失败使用独立限流；启用 Redis 时使用跨实例原子计数，Redis 故障时失败关闭。
- `X-Forwarded-For` 仅在直连对端属于显式受信代理网段时使用。
- 合同、审查、聊天、审批、任务、通知和风险接口执行角色或资源所有权检查；新增跨资源越权回归测试。
- 审查上传默认自动分类并自动写入合同中心；分类方法、置信度、依据、人工覆盖和合同版本关联均进入持久化记录。
- 报告中心和风险台账的指标及图表仅聚合当前账号有权访问的数据，并有越权统计回归测试。
- 上传校验扩展名、MIME、魔数、大小、DOCX 路径/压缩率/宏/外链、PDF 页数和图片像素；OCR 与 Office 转换有超时和隔离配置目录。
- 请求返回关联 ID；提供存活与依赖就绪检查；指标接口仅管理员可读。
- 应用容器非 root，启用只读根文件系统、capability 丢弃、进程/CPU/内存限制和健康检查。

## 已知限制

- 本仓库没有合法、完整、持续更新的法规数据源，不应把规则输出当作法律意见。
- 规则基准的 Gold 标注仍不完整；已有 precision/recall 只代表当前虚构样本回归，不代表法律准确率。
- JSON 兼容存储仍用于部分聚合服务；生产启用数据库后写入 PostgreSQL `app_state`，但尚未全部拆分为强约束关系表。
- 文档处理运行在 worker 容器内，尚未接入专用恶意文件扫描、无网络沙箱或 CDR 服务。
- 浏览器客户端仍把 access/refresh token 放在 `localStorage`；刷新令牌已轮换且服务端可撤销，但在完成 HttpOnly/SameSite Cookie 与 CSRF 设计前，生产部署必须把 XSS 防护和前端依赖审计作为硬门禁。
- 真实模型成本、token、延迟、准确率和供应商故障切换没有可验证生产数据。
- 合同自动分类属于辅助元数据：内容规则和模型结果均可能误判，关键合同仍需人工确认分类与适用审查模板。
