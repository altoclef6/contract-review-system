# 验收演示数据说明

以下内容仅用于本地验收和面试演示，不包含真实客户、合同或敏感信息。

## 软件开发服务合同

- 付款条件不明确：补充首付款、里程碑付款、尾款比例及明确到期日。
- 验收标准缺失：在附件中固化功能清单、测试方法、验收期限与逾期反馈机制。
- 知识产权归属不清：区分定制成果、背景知识产权、开源组件与第三方素材。
- 违约责任不对等：设置双方对等的逾期责任，并约定合理的累计上限。

## 办公场地租赁合同

- 押金退还条件模糊：明确退租交接、费用结清、扣款凭证及退还期限。
- 提前解约责任过重：区分有因解约与无因解约，并设置合理通知期和责任上限。
- 维修责任划分不清：区分主体结构、设施设备、日常维护与紧急维修责任。

## 员工保密协议

- 保密范围过宽：限定商业秘密的构成要件，并排除公开信息和员工既有知识。
- 保密期限不合理：按信息类型设置期限，商业秘密保护至其依法公开或失密。
- 违约金明显过高：设置合理上限，并允许按实际损失及过错程度调整。
