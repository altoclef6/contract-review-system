## 下载与运行

Windows 成品在 GitHub `v0.3.2` Release 中提供：

- `合同智审-v0.3.2-Windows-x64-安装包.exe`
- `合同智审-v0.3.2-Windows-x64-便携版.zip`

首次启动会初始化本地数据库。验收环境默认管理员账号：

- 账号：`admin@example.com`
- 密码：`Admin12345!`

该账号仅用于本地验收。正式部署必须立即修改管理员密码、JWT 密钥、模型凭据加密密钥和数据库密码。

## 演示顺序

1. 使用管理员账号登录。
2. 在工作台加载验收演示数据。
3. 打开法律知识库，查看法律文件、条文、风险规则和版本记录。
4. 上传 `samples/acceptance/软件开发服务合同.txt`。
5. 发起智能审查并查看条款级风险、修改建议和法律依据。
6. 对风险执行确认、驳回、整改、评论或分配操作。
7. 在报告中心查看并导出报告。
8. 使用员工账号验证只能查看公开有效条文，不能修改法律数据或风险规则。
9. 在操作日志中查看管理操作和审查追溯记录。
